5. Déploiement

Site 100 % statique. Render redéploie automatiquement à chaque push GitHub.

1. git push sur ahmeddavidfp-spec/tremorsi-site (branche main)
2. Render détecte le commit et publie (static site, publish dir ., pas de build)
3. Cloudflare sert le domaine et redirige www vers l'apex

Développement local

cd "Tre Mor Si"
python3 -m http.server 8765     # http://localhost:8765

Publier une modification

git add -A && git commit -m "description" && git push
# Render redéploie en ~1 minute

Configuration DNS (Cloudflare, zone tremorsi.com)

TypeNomCibleProxy
CNAME@tremorsi.onrender.comDNS only (gris)
CNAMEwwwtremorsi.onrender.comDNS only (gris)

Attention : garder les CNAME du site en DNS only. Passer en proxy orange empêche Render de vérifier le domaine et de renouveler son certificat.
Node (nécessaire pour wrangler) est installé en portable : export PATH="$HOME/tools/node/bin:$PATH" avant toute commande npx.

6. Email & formulaires

Réception - Cloudflare Email Routing actif

Gratuit, illimité en alias. Redirige vers une boîte existante.

  • contact@tremorsi.com → david@bems.be
  • MX, SPF et DKIM posés et verrouillés par Cloudflare
  • Console : zone tremorsi.com → E-mail → Email Routing

Envoi - FormSubmit

Service gratuit sans compte ni backend, appelé en AJAX.

  • Formulaires devis et contact → contact@tremorsi.com
  • Confirmation « ✓ Message envoyé ! » sans quitter la page
  • Repli automatique sur mailto: si l'envoi échoue
Le tout premier envoi déclenche un email d'activation FormSubmit à cliquer (une seule fois, définitif).

Ajouter une adresse de destination

Cloudflare → Email Routing → Adresses de destination → ajouter → la personne clique le lien de vérification reçu → créer/modifier la règle de routage.

7. Agenda, Instagram & bot Telegram

Le client gère sa semaine depuis Telegram, sans toucher au code. Le site se met à jour en quelques secondes.

Tressy écrit au bot @TreMorSiBot (boutons, aucune commande à retenir)
Worker Cloudflare agenda.tremorsi.com reçoit le webhook signé et écrit dans KV
tremorsi.com lit GET /agenda → bandeau du jour + semaine de la page contact

Parcours utilisateur

  • Elle écrit au bot → menu : 📅 Voir la semaine / ✏️ Modifier un jour
  • Choisit le jour → tape le lieu → tape les horaires → « ✓ C'est en ligne sur tremorsi.com ! »
  • Bouton 😴 Repos ce jour-là pour marquer un riposo
ÉlémentValeur
Codeworker/src/index.js
EndpointsGET /agenda (JSON public) · POST /telegram (webhook signé)
StockageCloudflare KV, namespace AGENDA, clé week
SecretsBOT_TOKEN, WEBHOOK_SECRET, ALLOWED_IDS
SécuritéWebhook validé par secret_token + liste blanche d'identifiants Telegram
RepliSi le Worker ne répond pas, le site affiche l'agenda par défaut codé en dur

Déployer une modification du Worker

export PATH="$HOME/tools/node/bin:$PATH"
cd worker && npx wrangler deploy

Mur Instagram

La page réseaux affiche les 6 dernières publications, servies par GET /instagram. Un cron tente un rafraîchissement chaque lundi 4h.

Limite connue : Instagram répond 429 aux serveurs Cloudflare, donc le rafraîchissement automatique échoue souvent. Dans ce cas rien ne casse : les publications précédentes restent affichées et le bot envoie un rappel Telegram. Mise à jour manuelle en 5 secondes : /instagram https://www.instagram.com/p/XXXX/
Solution définitive à mettre en place avec le client : Meta Graph API (gratuite et officielle). Nécessite le compte Instagram en Business/Creator lié à la Page Facebook, puis une app Meta. Le Worker existant l'appellera à la place du scraping.

Autoriser une nouvelle personne

# 1. Elle écrit au bot : il lui renvoie son identifiant Telegram
# 2. Ajouter cet identifiant à la liste (séparés par des virgules)
cd worker && npx wrangler secret put ALLOWED_IDS
Le token du bot peut être régénéré à tout moment via /revoke chez @BotFather - il faut alors le réenregistrer (npx wrangler secret put BOT_TOKEN) et refaire le setWebhook.

8. Référencement

En place fait

  • Titre, méta-description, canonical et un seul h1 par page
  • Attributs alt sur toutes les images
  • JSON-LD FoodEstablishment (nom légal, TVA, adresse, téléphone, réseaux)

  • Mentions légales en pied de page (obligation belge)

Google Search Console

  • Propriété tremorsi.com vérifiée par enregistrement TXT
  • Sitemap soumis - « Opération effectuée », 7 pages découvertes
  • Rapports complets disponibles après quelques jours de collecte
